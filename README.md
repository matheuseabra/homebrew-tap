# Matheus Seabra's Homebrew Tap

Homebrew tap for Matheus Seabra's command-line tools.

## Install

```bash
brew tap matheuseabra/tap
```

## Packages

### Formulae

- [`mbtop`](https://github.com/matheuseabra/mbtop) - Tiny, fast system monitor for terminal dashboard panes
- [`macos-calendar-tui`](https://github.com/matheuseabra/google-calendar-tui-macos) - Read-only terminal agenda for macOS Calendar

## Install a package

```bash
brew install matheuseabra/tap/mbtop
brew install matheuseabra/tap/macos-calendar-tui
```

## Update and uninstall

```bash
brew update
brew upgrade

brew uninstall mbtop
brew uninstall macos-calendar-tui
```
